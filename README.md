# Lab 5 – High-Dimensional Data Visualization Techniques

Streamlit app covering mosaic plot, trellis display, heatmap, multivariate scatter,
parallel coordinates, an animated 3D "grand tour", and a violin/box plot.
Switch between the original `tips.csv` and a custom Gapminder 2007 dataset in the sidebar.

## Setup

```bash
pip install -r requirements.txt
```

## Run

```bash
streamlit run lab5_app.py
```
